Set up Arr

Arr finds and downloads movies and TV shows for your Plex server. This takes a few minutes, and nothing is downloaded yet.

1 Sign in to Plex

Arr uses your Plex account to find your server and libraries. Your password is entered on plex.tv, never here.

If something goes wrong during setup or later, Arr sends a short note about the error to its developer (through Sentry, stored in the EU). Names, folders, addresses and passwords are removed first, and nothing about your library or what you watch is sent. What's sent.

Finding new movies

Arr finds TV shows on its own. To find movies you don't have yet, it needs a free key from TMDB, the movie database. It takes about five minutes, on a computer rather than a phone.

  1. Create a free TMDB account, and confirm your email if TMDB asks.
  2. Open your account's API page, request a key and accept TMDB's terms. If it asks about your app, it's personal, non-commercial use, and these answers are fine:
    Application name
    Arr
    Application URL
    https://github.com/newtonharry/Arr
    Application summary
    Personal media server that finds movies for my Plex library
  3. Copy the API Read Access Token (the long one) or the API Key, and paste it here:

No key yet? You can skip this: everything else works, and you can add a key later by running the install command again. Help with this step.

Arr uses TMDB and the TMDB APIs but is not endorsed, certified or otherwise approved by TMDB.
